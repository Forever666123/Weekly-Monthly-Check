# Weekly / Monthly Check

行动计划（2026-09-15 定稿）的两个自动检查邮件。收件人固定为 chenjiayuan955@gmail.com。

## 内容

| 文件 | 作用 |
| --- | --- |
| `.claude/skills/action-plan-weekly-check/SKILL.md` | 周检查邮件规范（第几周、LeetCode 累计基准、下周题型、说话习惯、刷题方法） |
| `.claude/skills/action-plan-monthly-check/SKILL.md` | 月检查邮件规范（本月/下月节点、月检查四项、PTE 阶段、提醒自己） |

两份 SKILL.md 是**规范的唯一真相来源**。要改内容（比如调整 LeetCode 每周题量、加关键日期、换轮换语句），改这里。

## 定时任务

在 claude.ai 的 Routines 里各建一条，cron 用 **UTC**：

| 任务 | 悉尼时间 | cron (UTC) | 首次生效 |
| --- | --- | --- | --- |
| 周检查 | 每周日 20:00 | `0 9 * * 0` | 2026-10-04（此前触发也不发） |
| 月检查 | 每月 1 号 20:30 | `30 9 1 * *` | 2026-11-01（此前触发也不发） |

时区说明：cron 只认 UTC，不跟随夏令时。`09:00 UTC` = 夏令时（AEDT，10 月初到 4 月初）悉尼 20:00，= 标准时（AEST）悉尼 19:00。两种情况下悉尼日期都还在同一天（周日 / 1 号），所以周数和月份的计算不受影响，只是冬天会早一小时到。

**定时任务必须挂上 Gmail connector**，否则触发出来的会话没有 `mcp__Gmail__send_message`，邮件发不出去。用 API / MCP 建的任务无法附带 connector，所以这两条要在 claude.ai 的 Routines 界面里建（或在界面里给已建好的任务补上 Gmail）。

## 日期口径

- 第 1 周 = 2026-09-28 至 2026-10-04。某个周日 X 的周数 = (X − 2026-10-04) ÷ 7 + 1。
- LeetCode 累计基准 T(n)：n ≤ 9 → 5n；10 ≤ n ≤ 22 → 45 + 15(n−9)；n ≥ 23 → 240 + 5(n−22)。
  校验点：T(4)=20，T(9)=45，T(13)=105，T(18)=180，T(22)=240。
- 补跑：触发日比该周的周日（或该月 1 号）晚 2 天以上，主题前加「(补发)」。
