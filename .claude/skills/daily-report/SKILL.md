## 0. 日期口径 —— 先读这条

定时任务在 **22:00 UTC** 触发，那一刻**悉尼已经是第二天早上 8 点**。
所以 `date -u +%F` 给出的是**昨天**的悉尼日期，绝对不能用。

今天的日期一律这么取：

```bash
TODAY=$(TZ=Australia/Sydney date +%F)        # 今天（悉尼）
TOMORROW=$(TZ=Australia/Sydney date -d "+1 day" +%F)
```

（容器里有 tzdata，`TZ=Australia/Sydney` 可用，已验证。）

夏令时：cron 只认 UTC，不跟随夏令时。`0 22 * * *` 在标准时（AEST，UTC+10）= 悉尼 08:00，
在夏令时（AEDT，UTC+11，10 月初到次年 4 月初）= 悉尼 09:00。
两种情况下悉尼日期都是同一天，上面的取法都对，只是夏天那半年晚一小时到。
要修就把 cron 改成 `0 21 * * *`，并把本节的「22:00 UTC」同步改掉。

## 2. 三块内容怎么判定

### 2.1 今天的时间线（课 / 打工 / 约好的事）

- 今天日历的全部事件，按开始时间排。全天事件排最前，标「全天」。
- 每条给：起止时间、标题、地点、以及 description 里**今天要动手的那部分**（例如「先给 tutor demo 上周的 lab」）。
- 打工班次**以日历为准**。日历里没有「上班」就是今天没班 —— 不要推测，也不要写「今天没班」这种废话行。
- 「固定信息」里今天本该有、但日历里没有的课：作为**待确认**条目列出，
  写清依据是什么、不确定的是哪一点。**不要当成既定日程写**。

### 2.2 今天到期的 deadline（含明早）

窗口 = 今天 00:00 → **明天 12:00**（悉尼）。

来源：日历里带 deadline / due / 截止 / 到期 字样的事件、「固定信息」里的日期表、过去 24 小时邮件里写明的截止日。

**窗口外的一律不写。** 不要写「最近的一个是……」——那是凑。

### 2.3 需要回的邮件

要同时满足：过去 24 小时内收到 + 需要 Leo 亲自回 + 他还没回。

**排除**：自己发给自己的（带 SENT 标签）；noreply / no-reply / notifications / updates / marketing 类发件人；
推广营销；订单、配送、账单、退款通知；安全登录提醒；群发问卷调查；
LinkedIn 等社交平台通知；Moodle 论坛转发的课程公告（不可回）。

**保留**：真人写给他本人、在问他事情或等他答复的；机构发的、明确要求他在期限内回复或确认的。

**已回过的排除**：同一 thread 里存在他自己的 SENT 回复，且晚于对方最后一封。

一封都没有 → 写「无」。可以补**一句**说明为什么（总封数 + 都是些什么类型）——
这一句是「无」的证据，不算凑，但只许一句。

### 2.4 明天的事，今天先动手

读明天的事件，只挑**今天不动手、明天就来不及或会更差**的。
明天只是普通上课/上班，不需要准备 → 这一节整块省掉。
真有 → 写清：明天那件事是什么、为什么今天就得动、今天具体做哪一步。

## 3. 第一步 —— HTML 页面

在会话里生成一个完整排版的 HTML 页面，写到临时目录（如 `/tmp/daily-report-$TODAY.html`），
然后把路径和内容输出到会话里。**不要写进仓库，不要 commit。**

要求：中文；手机宽度（~400px）能读；自带浅色/深色两套 token；
不引用外部图片；顶部一行摘要（几节课 / 几个 deadline / 几封待回邮件）；
下面按「时间线 / deadline / 待回邮件 /（明天要准备的）」分节。

某一节没内容 → 那一节写「无」，不要删掉这一节，也不要拿别的东西填。

## 4. 第二步 —— 纯文本邮件

- 收件人：`chenjiayuan955@gmail.com`

## 5. 工具拿不到怎么办

触发出来的新会话不一定挂得上 connector（本环境的 create_trigger 不支持 connectors 参数）。

- **日历读不到**（没有 `list_events` 工具，或调用报错）：时间线那一节写
  「⚠ 日历读不到（工具不可用），今天的日程无法确认」，**不要写「无」** ——
  「无」的意思是查过了确实没有，和没查过是两回事。deadline 一节同理。
- **Gmail 读不到**（没有 `search_threads`）：待回邮件那一节写
  「⚠ 收件箱读不到（工具不可用）」，同样不要写「无」。
- **只要 `send_message` 还在，邮件照发** —— 带着上面的警告发出去，
  这样 Leo 早上就知道任务跑了但缺数据，而不是收到一份看着正常的空简报。
- `send_message` 也没有 → 把完整简报输出到会话里，结束。
