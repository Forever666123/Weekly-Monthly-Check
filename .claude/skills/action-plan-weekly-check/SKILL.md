## 1. 算日期
今天日期按悉尼时间算（定时任务在 09:00 UTC 触发，此刻 UTC 日期与悉尼日期相同）。S = 今天或之前最近的一个周日（今天是周日就是今天；电脑没开导致补跑时，今天可能已经是周一以后）。

## 2. LeetCode 累计基准（9/15 定的「暑假冲量」方案）
第 n 周结束时累计应到 T(n)：
- n ≤ 9（2026-09-28 至 11-29，学期中，每周 5 题）：T(n) = 5n
- 10 ≤ n ≤ 22（2026-11-30 至 2027-02-28，暑假冲量，每周 15 题）：T(n) = 45 + 15 × (n − 9)
- n ≥ 23（2027-03 起，每周 5 题维持）：T(n) = 240 + 5 × (n − 22)

T(0) = 0。本周题量 = T(n) − T(n−1)；下周题量 = T(n+1) − T(n)。
校验：T(4)=20，T(9)=45，T(13)=105，T(18)=180，T(22)=240。

累计题数对应的状态：约 20 题时 Easy 都难受、要看题解，是正常的；约 50 题 Easy 能独立做；约 150 题大部分 Medium 能做；约 240 题够应付实习机考。

## 4. 本周刻意改的说话习惯（按 n 除以 4 的余数轮换）
- 余 1：答案封闭，不留话头 → 答完多给一个细节或反问一句，让对方接得上
- 余 2：过度客气、教科书腔 → 能直接说的就直接说
- 余 3：答情境，不答对方那句话 → 先接住对方刚说的那句
- 余 0：说完了还继续解释 → 说完就停，等对方问
（这四条影响面试，比 PTE 更近。）

## 5. 刷题方法（每周一条，余数同上）

- 余 0：关键是别停
